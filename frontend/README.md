# HyperSync frontend

React 19 + Vite + React-Bootstrap + Recharts. See the [root README](../README.md)
for setup, project structure and conventions.

```bash
npm run dev      # dev server on :5173
npm run lint     # oxlint
npm test         # node's built-in runner, no extra dependencies
npm run build    # production bundle in dist/
npm run check:css  # after a build: every Bootstrap class the code uses is in the trimmed CSS
npm run check    # all of the above
```
